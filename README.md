# Arkanoid

Игра арканоид на C++ с использованием библиотеки SFML.

## Управление

- **← →** или **A / D** — движение платформы

## Механики

### Блоки

- Разрушаемые и неразрушаемые блоки
- Блоки с несколькими жизнями (меняют цвет при ударе)
- Блоки, меняющие скорость мяча (ускорение / замедление)

### Бонусы

Выпадают при разрушении блоков, нужно ловить платформой:

- Очки (+100 / +1000)
- Изменение ширины платформы
- Изменение скорости мяча
- Запасная жизнь
- Случайная траектория мяча

### Очки

- +100 за каждый разрушенный блок
- +5000 за очистку уровня
- -1000 при падении мяча

## Запуск

В проекте уже есть SFML, однако, если это не так, то нужно установить её через Nuget
